# Bugs, limitations, and recommendations

No source changes were made. Severity describes user impact in the current console application. **Verified** means directly reproducible from the code or observed in the smoke run; **potential** means dependent on unusual data or environment.

| File / function | Behavior and why it matters | Severity | Status | Recommendation |
|---|---|---:|---|---|
| [`main.cpp`](../main.cpp), before/after similarity output | `finalScore` is stored as a fraction, but `originalSimilarity` and `rephrasedSimilarity` print it directly with `%`. A value such as 0.25 is printed as `0.25%`, whereas report output correctly shows 25%. | Medium | Verified | Multiply scores and their difference by 100 before adding `%`, or label them as fractions. |
| [`main.cpp`](../main.cpp), both `cin >> choice` sites | `choice` is uninitialized before extraction. If extraction fails (notably EOF), it is then read in a condition; reading an indeterminate `char` is undefined behavior. | Medium | Verified by source path | Initialize it and check stream state before branching; report/exit cleanly on EOF. |
| [`main.cpp`](../main.cpp), input and [`AIDetector.cpp`](../AIDetector.cpp), `extractFeatures` / `calculateScore` | Empty or punctuation-only input is not rejected. Feature extraction returns all-zero features, but the scoring formula gives 15 due to `0.15*(1-repetitionScore)`. User may see a nonzero AI-like score for no words. | Medium | Verified by control flow | Validate tokenized input before scoring/reporting, or define an explicit empty-input score and message. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), `ngramSimilarity` and `analyze` | Score is directional submitted-gram containment over the submitted vector, while reference trigrams are unique. Repeated query grams count multiple times; the resulting value is not symmetric set similarity and may be described misleadingly. | Medium | Verified | Name/document it as query trigram coverage, or use a symmetric set metric if that is the desired meaning. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), `analyzeAll` | The `frequency` parameter is ignored; `cosine` rebuilds both maps for every document. This wastes the submitted map already computed in `main`, and parameter/comment can suggest reuse that does not occur. | Low | Verified | Either pass/reuse the frequency map in cosine or remove the parameter when interfaces can change. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), `partition` / `quickSort` | Last-element pivot and strict `>` can yield O(R²) time and O(R) recursion depth for degenerate arrangements, including all-equal scores. | Medium for large corpus; low for 12 files | Verified algorithm property | Use randomized/median pivot or `std::sort` with a comparator; preserve expected tie policy explicitly. |
| [`DocumentManager.cpp`](../DocumentManager.cpp), `loadDocuments` | Checks `exists` but not `is_directory`; `directory_iterator` and permissions/filesystem operations can throw, and exceptions are uncaught. | Medium | Potential, dependent on path/environment | Validate directory type and handle `filesystem_error` with an explicit diagnostic. |
| [`DocumentManager.cpp`](../DocumentManager.cpp), `readFile` / `loadDocuments` | Failed file open logs and returns empty; valid empty files are also skipped. Caller cannot distinguish these outcomes. | Low | Verified | Return explicit status/result or handle read failure separately from empty content. |
| [`main.cpp`](../main.cpp), corpus path | `"data/reference"` is relative to current working directory. Launching from another directory logs missing-corpus and yields no comparisons even if the corpus is beside the executable. | Medium | Verified assumption | Resolve a configured path relative to project root/executable, or accept a corpus path argument and report it. |
| [`AIDetector.cpp`](../AIDetector.cpp), `calculateScore` | The output is named AI-likeness but is hand-weighted and has no labeled training/calibration evidence. High score cannot establish AI authorship; low score cannot establish human authorship. Normalization uses only upper caps, so external callers can pass negative fields and obtain invalid scores. | High as a claim limitation; not a runtime defect for extracted values | Verified | Clearly label as an unvalidated heuristic; calibrate on representative labeled data and clamp/validate API inputs if the range is promised. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), all metrics | Similarity only considers the 12 local synthetic reference files. A low score means low lexical overlap with that corpus, not originality or absence of plagiarism. Cosine/Jaccard are lexical and not semantic. | High as a claim limitation | Verified | State corpus coverage and scope in UI/report; expand/curate corpus and avoid definitive plagiarism/originality claims. |
| [`Paraphraser.cpp`](../Paraphraser.cpp), replacements | Fixed substitutions can change nuance, grammar, capitalization, and context; no semantic check confirms preservation. Regex replacement is not genuine contextual paraphrasing. | Medium as product limitation | Verified | Describe as rule-based rewriting; preserve case/context and review output, or use an evaluated language service if permitted. |
| [`Paraphraser.cpp`](../Paraphraser.cpp), regex loops | Every call recompiles each regex and scans the evolving text. This is avoidable overhead; standard regex worst-case can be superlinear. | Low for short paragraphs | Verified | Precompile immutable patterns once or use direct case-insensitive matching for these fixed literals. |
| [`main.cpp`](../main.cpp), trailing comments | Comments state the program does not call a rephraser and that Part 2 will add before/after analysis, but those features are implemented earlier in the same function. | Low | Verified | Update stale comments so the source narrative matches execution. |
| [`main.cpp`](../main.cpp), input sentinel | Sentinel is recognized only when the entire line is exactly `"END"`; leading/trailing spaces do not terminate. EOF is otherwise handled as end of input. | Low | Verified | Decide/document exact-line behavior or trim the line before comparison. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), index sizes | `results.size()` is narrowed to `int`; set sizes are cast to `int`; counts and products use `int`. Extremely large corpora/texts could overflow/narrow. | Low for current project | Potential | Use `size_t` consistently for sizes/counts and guard numeric products. |
| Project build selection | `main.cpp`, `tempCodeRunnerFile.cpp`, and `test_paraphraser.cpp` each define `main`; compiling all `.cpp` files together causes duplicate entry-point linker errors. No build configuration documents the production source list. | Medium for build usability | Verified source inventory | Add a build target that explicitly lists production sources and a separate test target. |
