# Audit findings and limitations

This page distinguishes fixes made during the current audit from remaining design limitations. No AI-authorship or plagiarism result should be treated as proof.

## Fixed and regression-tested

| File / area | Finding and resolution | Verification |
|---|---|---|
| [`main.cpp`](../main.cpp), validation | Empty, whitespace-only, and punctuation-only submissions previously proceeded to analysis. The entry point now rejects inputs that tokenize to no words with a failure status. | End-to-end tests for all three inputs. |
| [`main.cpp`](../main.cpp), yes/no input | Prompt reads now use full-line input, trim surrounding whitespace, retry invalid answers, and return safely on EOF. Outer and inner choices have distinct initialized names. | Invalid answer, each rephrase branch, and EOF tests. Strict `-Wshadow` build. |
| [`main.cpp`](../main.cpp), similarity comparison | Component scores are fractions; before/after values are multiplied by 100 before printing percentages. | End-to-end test verifies `0.00%` for both comparisons when no terms overlap. |
| [`AIDetector.cpp`](../AIDetector.cpp) | Empty features now score 0. Non-finite inputs are rejected; finite features and final score are clamped. Token/sentence counts use `size_t` and explicit numeric conversions rather than narrowing to `int`. | Core tests cover empty, whitespace, punctuation-only, long text, extreme values, NaN, and infinity. Strict `-Wconversion` build. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp) | N-gram similarity is explicitly symmetric Jaccard over deduplicated sets; empty/empty is defined as zero. Component and final values are clamped to [0,1]. Counts/index bounds use `size_t`; Quick Sort recurses on its smaller partition, preventing linear stack growth. | Core tests cover empty, identical, unrelated, partial, duplicate trigrams, sorted results, and 1,000 equal-score documents. Strict conversion build. |
| [`DocumentManager.cpp`](../DocumentManager.cpp) | Directory existence/type/status and iteration errors are checked and reported. Reads use bounded chunks, detect open/read failures, and retain RAII file closure. Empty documents are explicitly skipped. | Tests cover missing paths, non-directory paths, empty/readable/unreadable files and successful loading. |
| [`Paraphraser.cpp`](../Paraphraser.cpp) | Removed `format_first_only`; each matching word rule now replaces all whole-word occurrences instead of only the first. | Tests verify repeated replacements, phrase substitutions, capitalization, word boundaries, and technical strings. |
| [`ReportGenerator.cpp`](../ReportGenerator.cpp), claims | Report headings now identify local-corpus similarity, and output explicitly states the AI score and similarity are not proof of authorship, plagiarism, or originality. | Core tests assert the disclaimers and percentage output. |
| Documentation/build guidance | README now gives explicit C++17 production/test commands and accurately describes the heuristic, local corpus, and fixed-rule paraphraser. `tempCodeRunnerFile.cpp` and the paraphraser driver are excluded from the production command because they define separate `main()` functions. | Commands run with strict Clang warning flags. |

## Remaining limitations or non-defects by design

| File / function | Limitation | Severity / status | Recommendation |
|---|---|---|---|
| [`AIDetector.cpp`](../AIDetector.cpp), `calculateScore` | Fixed weights and surface features have no demonstrated calibration dataset or measured accuracy. It is a heuristic, not a trained authorship detector. | High limitation; behavior is explicit | Keep claims cautious. Any future calibration should use representative labeled data and report evaluation methodology and error rates. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), all metrics | The system compares only against the configured local corpus (currently 12 synthetic files); lexical overlap does not establish plagiarism or originality. | High limitation; scope is explicit in report | Describe scores as overlap with the configured corpus; do not make definitive authorship/originality claims. |
| [`Paraphraser.cpp`](../Paraphraser.cpp) | Fixed substitutions are not context-aware and cannot guarantee meaning or grammar preservation. | Medium limitation | Describe it as dictionary/rule-based rewriting; users must review output. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), `analyzeAll` | Its `frequency` parameter remains unused because cosine rebuilds maps for each document. This is redundant work, not incorrect output. | Low performance issue | Reuse the map or revise the interface only if performance justifies the API change. |
| [`SimilarityAnalyzer.cpp`](../SimilarityAnalyzer.cpp), Quick Sort | Last-element pivot can still cause O(R²) comparisons on degenerate input, although smaller-side recursion caps stack use at O(log R). Current local corpus is small. | Low for current data; theoretical worst case | Consider randomized pivot or `std::sort` if corpus size grows; retain testing for descending ranking. |
| [`main.cpp`](../main.cpp), reference path | `"data/reference"` is relative to current working directory. Launching outside the repository root can result in a missing-corpus message and no comparisons. | Medium environment assumption | Run from repository root (documented), or accept/configure a corpus path if needed. |
| [`main.cpp`](../main.cpp), input sentinel | `"END"` is recognized only when the entire line matches exactly; surrounding spaces do not count as the sentinel. EOF also ends collection. | Low defined behavior | This is documented; trim only if relaxed sentinel handling is desired. |
| [`DocumentManager.cpp`](../DocumentManager.cpp), return contract | `readFile` returns an empty string for both a valid empty file and a read failure, though failures are logged and `loadDocuments` separately prints that empty content is skipped. | Low API ambiguity; existing public interface retained | An explicit result/status type would distinguish the cases if the interface can later change. |
| [`Paraphraser.cpp`](../Paraphraser.cpp), regex rules | Patterns are compiled per invocation and each rule scans the current string; fine for the short fixed rule set, but avoidable overhead on very large text. | Low performance issue | Precompile immutable rules only if profiling demonstrates a need. |
